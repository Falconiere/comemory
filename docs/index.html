— comemory · developer memory for coding agents

Memory for agents, kept beside the code.

comemory saves the why behind a codebase as markdown, extracts the what from the repo, and returns both through one deterministic ranking. One Rust binary, one SQLite file, no daemon, no LLM in the loop.

Every codebase carries two kinds of knowledge: what the system does, readable from source, and why it does it that way, which evaporates into closed pull requests and chat threads. comemory fuses both into one local property graph. Markdown stays the source of truth; comemory.db is the rebuildable index.

— §02 · what it does

Eight things, each with a number attached.

  1. 01 Memory as markdownDecisions, bugs, conventions and discoveries as plain files with YAML frontmatter at ~/.comemory/memories/. Git-friendly and hand-editable. id = sha256(body)[:8] →
  2. 02 Hybrid retrievalFTS5 BM25 plus optional bring-your-own-vector ANN, fused by reciprocal rank fusion, with a four-tier lexical fallback ladder that ends in mined query expansions. rrf k = 60 · 4 tiers →
  3. 03 Identifier-aware searchA custom FTS5 tokenizer splits camelCase and snake_case, so parseFrontmatter matches parse_frontmatter matches frontmatter parsing. baked into the DDL →
  4. 04 Two-layer code graphindex-code mines co-change edges from git history and import edges per language, then materializes a weighted PageRank onto every symbol. 5 languages · 2 mined kinds →
  5. 05 Versioned code references--ref-file and --ref-symbol pin a memory to code at a git anchor; context reports each link as fresh, stale or ghost. blob + commit + branch →
  6. 06 A learning loopRecord which hits helped, score recall@k and MRR, mine reformulations, then grid-search or Thompson-sample the ranking knobs. Offline and deterministic. eval → mine → tune →
  7. 07 A local HTTP APIcomemory serve exposes every command core on a loopback-only, token-gated /api/v1 surface, with jobs that stream progress and logs. 256-bit token · loopback →
  8. 08 AST patternscomemory ast runs ast-grep structural patterns over Rust, TypeScript, JavaScript, Python and Go from the same binary. ast-grep-core 0.45 →

— §03 · install

One line to install, two commands to trust it.

Prebuilt binaries ship for macOS on Apple silicon and for Linux with glibc 2.35 or newer. The installer verifies the archive against the SHA-256 sidecar every release carries and refuses to continue without a checksum tool. Anything else builds from source with cargo install --path .. 

# the installer is attached to every release
curl --proto '=https' --proto-redir '=https' --tlsv1.2 -fsSL \
  https://github.com/Falconiere/comemory/releases/latest/download/install.sh | sh

# or Homebrew, on macOS and Linuxbrew
brew install Falconiere/tap/comemory

# detect what this machine and repo still need, then apply the parts you pick
comemory setup

# runtime health: checks[] + scalars, also as --json
comemory doctor
source of truth

vectors
Bring your own. Pass them with --vector or --vector-stdin; lexical search works with none.
