# Runtime SQL to toolu-orm implementation plan

> **For agentic workers:** Use superpowers:executing-plans for the shared
> execution bridge and superpowers:dispatching-parallel-agents for disjoint
> store families. Track completion in the checklist below.

**Goal:** Replace handwritten runtime queries with the existing toolu-orm
schema builders wherever they preserve behavior; report missing capabilities
to Falconiere/toolu-orm and document every remaining production SQL family.

**Architecture:** Keep the synchronous store connection and caller-owned
transactions. Generate SQL and bound values using the declared schema, then
execute through a small store-private bridge that preserves owned results,
row decoding, affected-row counts, and SQLite error classification.

**Tech stack:** Rust, toolu-orm 0.7.0, rusqlite 0.40, SQLite FTS5/sqlite-vec.

**Spec:** The user request in this session and the binding rules in AGENTS.md.

## Constraints

- Preserve result ordering, pagination, null handling, conflict semantics,
  transaction boundaries, and query performance characteristics.
- Do not substitute INSERT OR REPLACE for ON CONFLICT DO UPDATE: replacement
  deletes rows and can cascade into dependent data.
- Keep the driver confined to store/. No driver cursors escape the store.
- Keep shipped migration SQL byte-identical; it is the migration journal's
  historical payload. Test fixture SQL independently verifies the live schema.
- Do not hide unsupported SQL inside a new raw-query wrapper or reproduce an
  ORM inside this repository. Retain and link genuinely unsupported cases.
- Files stay below 300 code lines and functions below 100 lines.

## Conversion example

```rust
use toolu_orm::core::query_column::CommonOps;
use super::{orm, schema_code::{IndexedFiles, indexed_files}};

orm::execute(conn, IndexedFiles::delete()
    .filter(indexed_files::repo.eq(repo)).to_sql())?;
let query = IndexedFiles::select()
    .columns_typed(&[&indexed_files::blob_oid])
    .filter(indexed_files::repo.eq(repo))
    .filter(indexed_files::path.eq(path));
orm::query_optional(conn, query.to_sql(), |row| row.get(0))
```
