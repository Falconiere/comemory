Comemory

Agentic dev memory, semantic code search, and AST patterns in one binary.

  • Install
  • Usage

Installation

Install via Homebrew or build from source.

Homebrew

brew install Falconiere/tap/comemory

From source

cargo install --path .

Usage

Index a repository, then search it.

Indexing

Run comemory index-code inside a git repository.

Searching

Run comemory search-code "query" to rank symbols.
